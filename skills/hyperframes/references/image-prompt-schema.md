# AI 生图提示词规范 · image-prompt-schema

> hedj-factory 全流水线共用的 AI 生图（GPT-Image / gpt-image-2 类模型）提示词规范。
> 谁读：book-narration-video（封面兜底）、talking-head-edit（装饰性卡片素材）、hyperframes / website-to-hyperframes（分镜 stills / B-roll / 九宫格）。
> 铁律和 Visual Identity Gate 一致：**先有视觉身份，再写提示词**——调色板与字体必须能追溯到 DESIGN.md / visual-style.md / visual-styles.md 或用户明示。

---

## 什么时候用 /browse、什么时候用 AI 生图

**证据必须真，装饰可以生。** 这是本规范的第一分流：

| 素材用途 | 用什么 | 为什么 |
|---|---|---|
| 新闻报道截图、权威媒体页面、真实产品官网、真实数据来源 | **只用 gstack `/browse` 抓真图** | 这是**证据**。AI 伪造真实新闻/报道截图 = 造假，一票否决 |
| 书封（`cover.jpg`） | 先 `/browse` 抓官方书封；**抓不到才 AI 生成兜底**，且成片里注明是示意封面 | 官方封面是事实素材，AI 版只是占位兜底 |
| 示意型信息图 / 图表风卡片（不冒充真实数据源） | AI 可以 | 观众明白这是解说示意，不是引用截图 |
| 分镜九宫格 / 多格叙事 storyboard | AI 可以（走成本闸门） | 纯创作产物 |
| 虚构 UI mock、概念示意界面 | AI 可以，但**别混入真实平台的 UI 特征**（logo、标志性布局） | 避免被误读成真截图 |
| 海报 / titlecard 氛围图 | AI 可以 | 纯创作产物 |

**一句话**：真事用 `/browse`，示意用 AI；**永远不给真实新闻造假截图**。没装 `/browse` 时按 talking-head-edit 的纪律停下来要素材，别拿 AI 图冒充证据凑数。

## 六块提示词协议（6-block protocol）

每条生图提示词按以下六块组装，缺一块就容易翻车。写中文提示词（用户明确要英文除外）。

### 1. 主体与任务（subject/task）
一句话说清画什么、给谁看、干什么用。例：「为讲书视频生成《原子习惯》的示意书封」。

### 2. 构图与版式（composition/layout)
画面怎么排：居中/三分/网格几列几行、留白在哪、视线动线、层级谁大谁小。多格图必须写清格数与分隔方式。

### 3. 视觉风格与材质（visual style/materials）
**不许凭空发挥**——按优先级注入：
1. 项目 `DESIGN.md` 的 Colors / Typography / Style Prompt；
2. 项目 `visual-style.md` 的 `style_prompt_full` 与结构化字段；
3. 用户点名的 [visual-styles.md](../visual-styles.md) 8 预设之一（抄它的 hex 色板段落）。
把具体 hex 色值、字体气质、材质（纸感/胶片颗粒/扁平矢量/微噪点）写进提示词。三个来源都没有 → 先走 hyperframes SKILL.md 的 Visual Identity Gate 问答，再回来写。

### 4. 文字与标签（text & labels）
图内要出现的文字**逐字写出**（书名、标题、标签、轴名），标明语言（通常是简体中文）、大致字号层级与位置，并要求「中文必须可读、无错字、无乱码伪汉字」。不需要文字就明确写「画面内不出现任何文字」。

### 5. 画幅比例与输出格式（aspect ratio / output format）
明确比例与用途：竖屏卡片/封面 3:4 或 2:3；口播 widget 区横卡 16:9 或 4:3；九宫格整页 1:1。写清「输出单张 PNG/JPG」还是「单张内含 N 格」。

### 6. 约束与负面清单（constraints & negatives）
每条提示词末尾固定挂一段负面清单，至少包含：

```
不要：紫色霓虹赛博默认风、moodboard 式贴标签拼贴、把提示词原文渲染进画面、
水印/签名/logo、乱码或伪汉字、混入真实平台 UI 特征（如微信/抖音界面元素）、
多余肢体/畸变手指、低分辨率噪点。
```

风格来源（DESIGN.md 等）里的「What NOT to Do」条目也并入这一块。

## 填空模板（按用途取用）

### 模板 A · 书封兜底（book-narration-video `cover.jpg`）

> `/browse` 抓不到官方书封时才用；产物只喂 book 卡，成片口播或角标注明「示意封面」。

```
【主体】为讲书视频生成《<书名>》（<作者>）的示意书封，非官方复刻。
【构图】竖版居中书封正视图，书名占上 1/3，作者名居下，四周留白均匀。
【风格】<注入 DESIGN.md/visual-style.md 色板与气质，例：暖奶白底 + 珊瑚 #D97757 点缀，扁平现代书装设计，轻纸纹>。
【文字】书名「<书名>」大号可读；作者「<作者>」小号；中文无错字无乱码。
【画幅】2:3 竖版，单张 JPG。
【负面】<粘贴上方固定负面清单>；不要模仿原版封面的注册商标元素。
```

### 模板 B · 示意信息图 / 图表风卡片（talking-head chart/recap 类装饰素材）

> 只用于**示意**：真实数据引用必须 `/browse` 抓原报道。图内标注「示意图」。

```
【主体】示意信息图：<一句话主题，例：复利曲线 vs 线性增长>。
【构图】<横版左右对比 / 单曲线大图 + 3 条标注>，标题在顶部，来源角标写「示意图」。
【风格】<注入主题色板，例：theme.json 主色 + 暖奶白底>，扁平矢量，粗线条，无渐变。
【文字】标题「<标题>」；轴/标签逐字：<标签1>、<标签2>…；全部简体中文可读。
【画幅】16:9 横版单张 PNG。
【负面】<固定负面清单>；不要伪造具体数据数值与真实媒体版式。
```

### 模板 C · 叙事多格 / 九宫格 storyboard

**单格（cell）**：

```
【主体】分镜第 <n>/<N> 格：<该拍什么，一句话>。
【构图】<镜别：远/中/特写>，<机位与主体位置>；与前后格保持同一主角与场景连续性。
【风格】<全组九宫格统一注入同一段 style_prompt_full / 色板，逐格不许换风格>。
【文字】画面内不出现任何文字（字幕由 hyperframes 后期加）。
【画幅】<单格比例，如 16:9>，单张 PNG。
【负面】<固定负面清单>。
```

**整页（full-grid）追加约束**：

```
单张 1:1 画布等分 3×3 九格，格间细白缝分隔；九格同一主角、同一风格、同一色板；
按 <左上→右下> 顺序叙事：<每格一句话，共 9 句>；格内不编号、不加文字。
```

### 模板 D · 海报 / titlecard 氛围图（可选）

```
【主体】<片名/章节名> 的开场氛围海报，情绪：<例：克制的紧张感>。
【构图】大留白 + 单一视觉锚点，为后期叠 HTML 大字预留 <上/中> 部安全区。
【风格】<注入色板>；氛围优先，细节克制。
【文字】画面内不出现任何文字（标题由 titlecard 组件叠加）。
【画幅】<1080x1920 竖版 9:16 / 1920x1080 横版 16:9>，单张 PNG。
【负面】<固定负面清单>。
```

## 成本闸门（批量九宫格 / 多格生成必过）

对齐项目「配额优先」纪律：**生成之前先报账，超阈值必须等用户确认**。

- **触发条件**：单次任务 >9 格（>1 张九宫格整页），或需要多轮重生成时。
- **过闸动作**：生成前打印预估——
  ```
  预估：<N> 格 / <M> 次生图调用 / 约 <T> 分钟 / 约 <C> 元（或 <K> 次配额）
  超过阈值（>9 格或 >1 张整页），等你确认再跑。
  ```
- 用户确认前**一格都不生成**；确认后逐批出图，每批完成报实际消耗。
- ≤9 格的单页任务可直接跑，但仍在开跑时报一行预估。

## 禁止事项（What NOT to Do）

1. **紫色霓虹赛博默认风**——没有风格来源就先过 Visual Identity Gate，不许用模型默认审美。
2. **moodboard 式贴标签拼贴**——产物是成片素材，不是风格参考板；不要在图里贴 "style: xxx" 标签。
3. **把提示词原文渲染进画面**——提示词是指令，不是画面文字。
4. **水印 / 签名 / 平台 logo**。
5. **乱码中文 / 伪汉字**——中文文字必须逐字指定且要求可读；生成后肉眼验字，错字重生成。
6. **混入真实平台 UI 特征**——虚构 UI mock 不许长得像微信/抖音/X 的真界面。
7. **AI 伪造真实新闻/报道/数据截图**——见开头分流表，一票否决。
